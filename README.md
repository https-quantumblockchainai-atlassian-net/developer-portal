## Getting Started

To run the Thoth Guardian platform locally, follow these steps:

### Prerequisites

-   Node.js (v18.x or higher)
-   npm or Yarn
-   Git

### Installation

1.  **Clone the repository:**
    \`\`\`bash
    git clone https://github.com/crystalalchemist/thoth-guardian.git
    \`\`\`

2.  **Install dependencies:**
    \`\`\`bash
    npm install
    \`\`\`

3.  **Set up Environment Variables:**
    Create a `.env.local` file in the root of the project and add your API keys.
    \`\`\`
    OPENAI_API_KEY=your_openai_api_key
    # Add other API keys as needed for integrations (e.g., GROQ_API_KEY, XAI_API_KEY, FAL_KEY, DEEPINFRA_API_KEY)
    \`\`\`

4.  **Run the development server:**
    \`\`\`bash
    npm run dev
    \`\`\`

    Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.
